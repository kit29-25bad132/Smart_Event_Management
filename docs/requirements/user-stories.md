# User stories

| ID | Story | Acceptance summary |
|---|---|---|
| US-001 | As a user, I can register and log in | Valid account receives JWT; invalid credentials fail safely |
| US-002 | As an admin, I can create and update events | Venue, time and capacity rules are enforced |
| US-003 | As a user, I can discover events | Search/filter results are paginated and role-safe |
| US-004 | As a user, I can register once and cancel | Capacity and duplicate rules are atomic |
| US-005 | As an admin, I can manage venues | Venue capacity and conflicts are visible |
| US-006 | As a user, I can ask policy questions | Answer includes sources or an evidence-unavailable response |
| US-007 | As an authorized user, I can ask the assistant to act | Assistant confirms destructive actions and uses tools safely |
| US-008 | As an admin, I can inspect system activity | Dashboard shows scoped statistics and agent/tool status |
