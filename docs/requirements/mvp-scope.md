# MVP scope

**In scope:** registration/login/JWT/RBAC; event and venue CRUD; availability; participant registration/cancellation; search/filter; policy/FAQ RAG; controlled agent tools; dashboard summaries; audit and agent observability; tests and deployment design.

**Out of scope for MVP:** payments, external calendar sync, multi-tenancy, mobile apps, advanced recommendations, autonomous destructive actions, and unapproved integrations. Mandatory requirements are the FR items marked Must; recommendations are explicitly marked REC.
