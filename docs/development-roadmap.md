# Eight-week roadmap

1. **Week 1 — Foundation:** repository, environments, health checks, documentation (implemented in Phase 0).
2. **Week 2 — Identity:** authentication, roles, secure sessions.
3. **Week 3 — Event domain:** events, venues, availability, validation.
4. **Week 4 — Participation:** registration, cancellation, notifications.
5. **Week 5 — Agent tools:** LangGraph workflow, business tool calling, guardrails.
6. **Week 6 — RAG assistant:** policies, FAQs, pgvector retrieval, citations.
7. **Week 7 — Product quality:** dashboard, chat UI, tests, logging, observability.
8. **Week 8 — Delivery:** Docker, CI/CD, cloud deployment, monitoring, security review.
